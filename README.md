# Автотесты для «Моментов»

[![tests](https://github.com/holyboga/momenty-tests/actions/workflows/tests.yml/badge.svg)](https://github.com/holyboga/momenty-tests/actions/workflows/tests.yml)

API- и UI-тесты на **Playwright + TypeScript** для приложения «Моменты» — закрытой свадебной ленты
(вход по QR без регистрации, фото/видео/голос/текст, реакции, капсула времени).

## Что покрыто

**29 тестов: 21 API + 8 UI.** Прогон целиком — около 15 секунд после старта сервера.

| Слой | Сценарии |
|---|---|
| API | health; вход по приглашению (валидный/битый токен, пустое имя, граница 40 символов, битый JSON); 401 без сессии; текстовый момент (создание, пустой текст, граница 500 символов, неизвестный тип); капсула (запечатанный момент скрыт из ленты и по прямой ссылке); скрытие своего момента и запрет чужого; реакции-переключатели, эмодзи вне списка, 404; владельческие настройки (owner 200 / guest 403 / anon 401); порядок участников |
| UI (Pixel 7) | вход гостя по QR-ссылке; редиректы без сессии и с битым токеном; создание текстового момента через «+» с проверкой счётчика и отображения в ленте; запечатывание в капсулу; страница участников с «(вы)»; экран проектора с QR по ключу и редирект без ключа |

## Запуск

```bash
npm install
npx playwright install chromium chromium-headless-shell

npm test            # bootstrap + все тесты
npm run test:api    # только API
npm run test:ui     # только UI (мобильный Chromium)
npm run test:headed # UI с окном браузера
npm run report      # открыть HTML-отчёт
```

Приложение «Моменты» (приватный репозиторий) должно быть склонировано рядом — в `../present` — или указано
переменной `APP_DIR=/путь/к/приложению`; в нём должны быть установлены `node_modules`. Обычный `npm run dev` приложения на порту 3000 нужно остановить: локальная база
PGlite однопроцессная.

## Как это устроено

1. **`scripts/bootstrap.mjs`** — до старта сервера: `migrate` → `seed` → открывает двери и закрывает
   капсулу (`force-settings.mts`) → разбирает из вывода seed гостевой токен, сессии владельцев и
   экранный ключ → пишет `.auth/links.json`.
2. **`scripts/start-app.mjs`** — Playwright поднимает `next dev -p 3100` как `webServer` и гасит после прогона.
3. **`scripts/app-env.mjs`** — изоляция от прода: `DATABASE_URL`, ключи S3, VAPID и Telegram
   принудительно пустые, поэтому приложение работает на PGlite и файловом хранилище в `.data/`.
   В `.env.local` приложения лежат ключи от Neon и Яндекс S3 — тесты до них не дотягиваются.
4. **`src/fixtures.ts`** — гость через API (`guest`), владелец по личной ссылке (`ownerApi`),
   анонимный контекст (`anonApi`); для браузера cookie гостя подкладывается через `storageState`,
   а тесты без сессии переопределяют его пустым.
5. **`src/pages/*`** — Page Objects: локаторы и действия отдельно от проверок.

Тесты создают данные с уникальными суффиксами и не зависят друг от друга — можно гонять параллельно.

## CI

`.github/workflows/tests.yml` — на каждый push: клонирует приватное приложение по секрету
`APP_REPO_TOKEN` (fine-grained PAT с правом Contents: read на репозиторий приложения; задаётся в Settings → Secrets → Actions), ставит зависимости и Chromium, запускает `npm test`, сохраняет HTML-отчёт артефактом. Без секрета прогон падает на шаге клонирования — это ожидаемо для форков.
